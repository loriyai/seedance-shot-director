# 声画联合预算

先规划自然声音、必须串行动作和观众需要读清的关键时刻，再分配视觉边界。有对白时声音不依赖镜头重启；动作密集或无对白时以动作完成和观看时间为主，不能只优化最少块数。

1. 根据来源分话轮，估计净发音时间与停顿，按 [dialogue-capacity.md](dialogue-capacity.md) 保留估计依据。
2. 给动作标并行或串行：边走边说取实际重叠覆盖，先走到门前再说按顺序累加。部分重叠按真实区间求并集，不能一律相加或取最大值。
3. 口部和身体条件允许时才并行；人物未听见或看见刺激之前不产生已知反应，但观众可在人物之后获知信息。
4. 为动作结果、文字阅读、包袱和关键回应留有可读时间。增强描述变多不自动增加片长；没有作用的停顿不保留。
5. 最后切视觉镜头；完整15秒默认五镜，可按表演与连续运镜需要调整。每镜常见1–6秒，短于1.5秒只承担可迅速辨认的信息或反应，不能塞复杂动作。建议区间不是平均分镜模板。
6. 容不下或过松时重划相邻来源边界；完整收尾按 [generation-block-splitting.md](generation-block-splitting.md)，不默认暂存短尾。

逐镜校验台词片段：以该片段实际结束减开始再减自身停顿为净时间；各片段声音区间连续覆盖话轮且停顿之和等于整句预算。整句可说完但某镜片段过密仍报错。跨场景首末各至少1秒无口播先从容量中预留，禁止通过晚起声强行对齐尾部。

时间用连续绝对区间，通常整数或一位小数；首镜0秒、无缝无重叠、末镜等于块标题实际时长。话轮另有声音区间，允许跨镜但要与实际台词片段匹配。静音收束与连续剪辑分开处理，按 [model-and-production-config.md](model-and-production-config.md) 执行。
