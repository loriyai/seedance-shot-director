# 分镜前剧本增强与审核

## 目的与边界

本流程称为“剧本表演增强”，兼容“优化分段剧本”命令；仅在当前指令或已保存的本任务偏好选择增强时启用。默认轻度，不新增独立反应节拍。目标是在不改变剧情、台词、信息顺序和动作结果的前提下，补足可见的人物动作、表情与表演细节，发现文字问题和逻辑疑点，并让用户在分镜前审阅。

轻度只细化已有动作、姿态与明确表演；标准档仅在用户明确选择后允许下文白名单内有依据的新反应。不要为了完成增强数量而修改已足够清楚的原句。

剧本增强不是剧情改写。不得为了让内容更精彩、更完整或更顺畅而发明事件、对白、人物动机、关系、能力、关键道具、冲突结果或世界观事实。

## 版本与来源状态

收到每个新片段后，先在后台建立并保持以下状态：

- `原版 V0`：用户发送的片段原文，是不可覆盖、不可重写的永久基线。
- `修订原版 V0.x`：只吸收用户明确确认的错别字、漏字、多字、标点、说话人、表现方式修订，以及明确接受的独立编剧建议；首次修订为 V0.1，之后依次为 V0.2、V0.3……。每版均另存，不覆盖 V0 或旧版 V0.x，也不得吸收优化稿中的动作、表情和细节扩写。
- `当前原版基线`：没有 V0.x 时为 V0；存在 V0.x 时默认使用编号最高的 V0.x。用户明确要求“最初原版 V0”时才切回未经修订的 V0。
- `当前审阅稿 Vn`：基于当前原版基线生成或经用户局部修改后的带标记版本。每次输出都递增版本号。
- `当前分镜来源`：只能是当前原版基线，或用户发送“确认剧本”后由当前审阅稿清理标记得到的确认版本。

“重新优化剧本”必须重新读取当前原版基线，以新的优化思路生成下一个审阅版本；不得以任何旧审阅稿为底稿继续叠加。“使用原版剧本”立即把当前分镜来源设为当前原版基线；“使用最初原版 V0”才把当前分镜来源设为 V0。历史版本可以保留供对照，但不得继续充当活动底稿。

在用户选择“不优化，直接按原版分镜”、发送“使用原版剧本”或发送“确认剧本”之前，不得拆生成块或输出分镜。

## 不可改变的叙事不变量

优化前建立来源保护清单，并在输出前逐项复核：

- 事件及其发生顺序不变。
- 场景、时间、人物身份、人物关系和行动目标不变。
- 进场、离场、位置跳转和信息揭示顺序不变。
- 关键道具的存在、归属、状态和用途不变。
- 行动的成败、伤势、胜负、死亡、获取或失去等结果不变。
- 台词、旁白、OS、独白的字词、语序、说话人和类型逐字不变。
- 用户提供的 `@素材` 名称、绑定对象和状态版本逐字不变。

用户明确确认错漏字、标点、说话人、表现方式，或明确接受独立编剧建议中的来源改写时，将其记录为“用户修订来源”，同时同步生成下一个 V0.x。基线内容未变则不新建空修订。若一次确认包含多项修订，应合并进入同一个新版本，不得为每个字分别递增版本。用户确认整份审阅稿时，其中已明确标为文字修正或用户修订的项目视为获准同步；普通动作增强不进入 V0.x。普通表演增强不代拟替换台词。用户要求编剧建议时可在审阅正文之外列原句、候选改法、理由与影响；只有明确接受的项目才进入新 V0.x，不能用“确认表演增强”推定接受旁列建议。不得覆盖 V0 或既有 V0.x。

## 允许的受控增强

轻度仅把下列与原文已有动作/表演相对应的执行细节原位合并；标准档才可添加有来源依据的新反应。每条记录来源位置、作用和并行/串行属性，区分原文明示、上下文可确定、制作设定与未知。两档均不得建立新剧情事实：

- 视线、焦点、面部微表情、呼吸、姿态、步态和手部细节。
- 原文动作的可见起点、过程、接触点、力度反馈与既定结果。
- 对现有台词、动作或环境刺激的短暂非语言反应。
- 与原文已出现道具和场景构件的轻量互动，不改变其归属或状态结果。
- 能由上下文确定的站位、距离和朝向变化。
- 服务于既有氛围的轻量环境反馈，但不得把天气、异象或声音写成新的剧情原因或线索。

每条获准新增内容至少承担情绪、人物关系、空间连续性、信息强调或动作衔接中的一项功能。不得给每句台词机械追加动作，也不得连续用皱眉、握拳、凝视、冷笑、转身或深呼吸凑细节。

## 增强动作的执行时序

优化稿增加的是画面信息，不默认增加成片时长。后台为每条细节增强或新增动作标注执行方式：

- `并行动作`（默认）：与当前台词、OS、旁白、行走、回忆画面或听者反应同时发生，不单独增加口播时长或生成块数量。
- `必须串行动作`（例外）：只有原文明确“先、再、随后、说完后、看见后”等先后关系，或动作存在无法同时完成的物理依赖时使用；记录依据后才可增加时长。

不得因为审阅稿文字更长、动作描述更细，就把每个动作按顺序累加或把一句连续台词拆成多个慢镜头。确认后的干净优化稿进入分镜时，先恢复连续声音轨，再把并行动作覆盖到对应关键词或语义段上。

## 原位替换与语义去重

- 原稿已经写明某个人物的动作、表情、姿态或状态时，必须把增强细节合并进该原句，使用 `🟦【细节增强：原“……”】` 标记；不得保留原句后再追加同义扩写。
- 仅标准档中，原稿完全没有对应节拍且新增内容符合允许范围时，才使用 `🟩【新增动作】`。同一人物、同一动作或同一结果的具体化不属于新增动作。
- 输出前检查每个增强句及其相邻一至两句。若出现“同一主体＋同一动作、状态或结果”的重复表达，合并为一个可执行动作；合并只消除表述重复，不得删除来源节拍。
- 审阅稿中的“原……”只用于对照。用户确认后，干净版本只保留增强后的合并句，不保留被替换原句或标记说明。

## 禁止的隐性改编

不得新增或擅自确定：

- 新事件、新冲突、新反转、新伏笔或新结局。
- 原文没有依据的内心想法、真实动机、立场变化或情感关系。
- 拔剑、攻击、跪下、拥抱、流泪、递交物品、受伤等会改变关系或事件含义的动作。
- 新人物、新对白、新旁白、新 OS、新称谓或说话人。
- 新道具、关键证据、法术能力、伤势、服装状态或世界观设定。
- 没有来源依据的进场、离场、转场、时间跳转、地点、季节或天气事实。
- 对矛盾剧情的自作主张修补。

如果一个动作既可以理解为普通表演，也可能改变动机、关系、信息或结果，视为剧情动作，不得添加。

## 文字与逻辑检查

按以下等级处理，不把“检查”误当成“自动改写”：

1. **动作说明中的确定文字错误**：明显错别字、重复字、漏字或标点错误，可以做最小修正，并用 `🟨【文字修正：原“……”】` 标记修正后的文本。
2. **动作说明中的表达问题**：仅当主语和原意唯一明确时，允许做最小语序或指代整理，并用 `🟦【表达调整：原“……”】` 标记；存在两种合理解释时只列为疑点。
3. **台词、旁白、OS、独白中的疑似错误**：原句保持不变，在紧邻位置用 `🟥【文字疑点：……；因口播原文锁定，暂未修改】` 提示。
4. **剧情或连续性问题**：人物位置、道具归属、时间线、因果、说话人、行动目标或结果冲突时，用 `🟥【逻辑疑点：……；未擅自修改】` 标记。

用户明确确认上述文字问题、说话人或表现方式后，使用 `🟨【用户修订：……】` 标记并同步生成下一个 V0.x，不再保留为红色疑点。表现方式可以调整既有内容由谁朗读、作为对白/旁白/OS 的类型，或是否显示为画面文字，但必须保持用户要求锁定的内容和信息顺序；用户要求不显示文字时，不得设计文字特写，可改由其指定的角色、系统或旁白口播。

影响说话人、行动目标、信息顺序、关键道具、时间空间或冲突结果的逻辑疑点属于 P0。即使用户发送“确认剧本”，也必须先请用户明确该项；不影响理解和分镜执行的非阻断疑点可保留原文并继续。

## 审阅标记与输出

颜色在不同界面和复制环境中不可靠，统一使用可搜索的文本标记：

- `🟩【新增动作】……`
- `🟦【细节增强：原“……”】……`
- `🟨【文字修正：原“……”】……`
- `🟨【用户修订：……】……`
- `🟦【表达调整：原“……”】……`
- `🟥【文字疑点：……；因口播原文锁定，暂未修改】`
- `🟥【逻辑疑点：……；未擅自修改】`

未改变的原文保持普通文本。输出完整审阅稿，不只输出修改清单；标记紧邻对应位置，避免用户在正文和说明之间来回查找。标题使用：

```text
优化剧本 V1（审阅稿｜基于原版 V0）
```

标题中的基线版本必须写实际使用的版本；若基于最新修订原版，则写成“基于修订原版 V0.1”“基于修订原版 V0.2”……。

正文结尾固定提示：

```text
表演增强审阅稿已生成，修改和疑点均已标记。可简列变化摘要，不以修改数量作为质量指标。

1. 你可以直接指出任意段落或标记，要求局部修改。
2. 最终修改完成后发送“确认剧本”，我会以当前优化稿开始分镜任务。
3. 发送“重新优化剧本”，我会放弃当前优化思路，从原版分段剧本重新优化。
4. 发送“使用原版剧本”，我会跳过优化稿，直接以原版分段剧本开始分镜。
```

## 审阅期间的命令语义

### 局部修改

用户指出段落、原句、标记或位置并提出修改要求时，以当前审阅稿为底稿：

1. 只改变用户指定位置及维持上下文连贯所需的最小相邻内容。
2. 未指定的原文、已接受增强和标记保持不变。
3. 新版本仍输出完整审阅稿并递增版本号。
4. 表演增强不突破叙事不变量；请求改变剧情或台词时，用户已提供确切新原文则按用户修订保存，否则另给具体编剧建议供选择。获准后形成新来源，不能在表演稿中暗改。

如果用户只说“不满意”但无法确定位置或目标，先请其指出具体段落或期望效果。

### 重新优化剧本

忽略所有旧审阅稿的新增和表达方案，从当前原版基线重新检查并生成新的完整审阅稿。版本号继续递增，以免与旧稿混淆。用户明确要求从“最初原版 V0”重新优化时，才使用未经任何修订的 V0。

### 确认剧本

先完成 P0 检查。没有未解决的 P0 时，把当前审阅稿转成干净确认版本：

- 保留用户确认的新增动作和修正后文字。
- 把获准的错漏字、标点、说话人和表现方式修订同步写入下一个 V0.x；动作、表情和细节增强只进入干净确认版本，不进入 V0.x。
- 删除 `🟩/🟨/🟦` 标记及修正说明，只保留干净正文。
- 所有未获用户明确改写授权的台词、旁白、OS 和独白仍保持当前原版基线原文。
- 删除非正文疑点说明；疑点从未构成自动修复依据。
- 将干净版本锁定为当前分镜来源，然后进入分镜预诊断和生成。

审阅标记、版本标题、结尾提示和疑点说明绝不能进入 Seedance 生成块。

### 使用原版剧本

将当前分镜来源锁定为当前原版基线，忽略审阅稿的动作、表情和细节增强，直接进入分镜预诊断和生成。若用户明确发送“使用最初原版 V0”，则使用未经任何用户修订的永久基线。

## 输出前质检

- 逐句核对台词、旁白、OS、独白和说话人是否与当前原版基线相同；用户修订项须与最新 V0.x 一致。
- 核对事件数量、顺序、信息揭示顺序及动作结果是否未变。
- 核对每个新增动作是否可见、可表演且有来源依据。
- 删除重复、模板化或只为堆砌细节的动作。
- 检查原稿已有动作是否均采用原位替换式细化，并检查相邻一至两句不存在同主体、同动作或同结果的语义重复。
- 核对每个增强动作已标为并行或必须串行；默认并行。只有存在原文先后依据或物理依赖的必须串行动作才增加自然表演时长并可能增加生成块，不能因增强文字变多自动扩块。
- 核对所有修正、调整和疑点是否带有正确标记。
- 按 [project-state.md](project-state.md) 确认 V0 与所有 V0.x 均完整可用，当前原版基线编号正确，且“重新优化剧本”没有沿用旧审阅稿。
