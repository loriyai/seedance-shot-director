# 独立生成块契约

## 必填块头

```text
生成块 01｜15秒｜16:9
<实际中文视觉特征与当前声音方案>
人物：本块人物身份、必要稳定外观、服装状态；晚入场注明首次可见镜头，画外声音注明不入画。
场景：地点、固定结构与来源所需道具位置。
本块氛围与站位：当前光线、氛围及世界内稳定空间关系。
收尾方式：独立收束
```

风格行在标题后，不能留占位符。音乐与声线从制作配置编译，不固定相反的全局要求。未提供素材时省略素材行，提供时精确保留名称和绑定。必要的 `口播段` 放镜头前，格式见 [prompt-template.md](prompt-template.md)。

块头只写稳定事实，不提前执行入场、拔刀、倒下或表情变化；首镜交代实际起点。块内事实不机械重复，跨块仍重述必要身份、空间和状态，以便单独投喂。

## 镜头与声音

每镜以 `[镜头N]` 开始，必填时间区间、画面与动作、摄影机与构图。一个编号只是一镜，不暗藏反打/插镜；主体关系、景别、观察角度、固定或一个主运镜可执行。表演、光线声音、文字、台词、进入本镜的必要衔接按需出现。

来源事件发生一次，可跨镜呈现过程；台词逐镜片段合起来逐字等于来源，人物与声音类型不变。带ID的口播段不复述正文，逐镜台词不重复全文。台词时段必须与镜头区间和收尾方式一致。

时长与镜数按 [generation-block-splitting.md](generation-block-splitting.md)：完整15秒严格五镜；30秒通常8–12镜；允许最后两块以实际时长自然收尾。标题必须写实际时长和画幅，不用缺失标题的默认值伪装通过。

## 两种展示

执行简版默认只输出可执行块与必要的块外设置/未解决事项。导演详版另附块外来源映射、观看重点、时间预算、切镜依据及连续性摘要；复制正文仍用同一模板，不倾倒后台全字段。

独立收束最后0.3–0.8秒无对白，允许动作/环境声持续；连续剪辑非终结块与来源硬切按各自方式处理。不引用未提供的上一块画面，不以“原来的位置”代替当前起点。
