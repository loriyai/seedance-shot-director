# 独立生成块契约

块标题写实际时长和画幅，下一行写当前风格与实际配乐选择；随后给出“人物”“场景”“本块氛围与站位”。不输出收尾方式、口播ID、语速档、停顿预算或内部台账。

人物栏仅列姓名、必要阶段、实际素材绑定；晚入场或画外身份按需要说明。不自行设计外貌、发型、体型或服装。衰老、破衣、伤势等剧情状态在对应镜头保留。实际素材标识逐字绑定，未提供则不虚构。

每镜有连续时间区间、“画面与动作”“摄影机与构图”“环境音效”；有台词时按 prompt-template.md 输出自然语言声音安排和具名台词，环境音效紧随全部台词之后，以“；”分隔。表演、剧情内文字和进入本镜的衔接按需要出现。

一个编号只是一镜。来源事件发生一次，过程和声音可跨镜；片段合起来逐字等于来源，人物和声音类型不变。动作栏保留可见动作、空间与同步，不重复概述对白。镜头数量按 generation-block-splitting.md，15秒默认五镜，有导演依据可调整。

每块自包含，不引用未提供的上一块画面。后台保留完整入口、出口、话轮、连续性和收尾策略；正文写真正需要模型执行的状态与时间。跨场景首尾各至少1秒无口播且画面持续，包含在块时长内；同场连续块不机械套用该规则。详细规则见 camera-transition.md。

编译器同时核对后台规划和直投正文的台词、时间与身份一致性。执行简版只交付模型需要的指令；导演详版另附块外审阅信息。
