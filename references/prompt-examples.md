# 可核对的完整示例

## 原生30秒：雨夜收信

以下是独立教学剧本，不能把人物、动作或道具套进用户原文。来源：

```text
雨夜院内，林舟提着灯，沈遥站在门内石阶旁。门外传来敲门声。
林舟：“门外有人，你去看看。”
沈遥靠近门听了听。
沈遥：“是送信的，我认得他的声音。”
沈遥打开院门。信使站在门外，把手中的信递过门槛。林舟提灯上前接信，查看封口。信使行礼后退回雨中，沈遥关门。林舟与沈遥沿石阶回到院内桌前，林舟将信和灯放在桌面。
```

执行设置：Seedance 2.5，实际30秒，16:9，独立收束，无配乐。光线属于本示例制作设定，人物外观以用户素材为准。

## 轻度增强的边界

原文“林舟把信放在桌上”，轻度可原位细化为“林舟把信放到面前桌面，松开手指，信留在桌面”。不能无来源加“迟疑、攥皱信纸、眼含泪光”等新反应。审阅时加细节增强标记；确认版删除标记。需要新反应先选择标准档并检查来源；台词改写另列编剧建议。

## 实际短尾

17秒自然内容可以在入口允许、语义边界成立时安排13秒和4秒，镜数按实际短块规则；并非要求17秒片段一定拆两块。2.5入口若允许17秒且目标30秒，可以一个17秒块完整表达。15秒默认五镜，可按表演和连续运镜需要调整。
