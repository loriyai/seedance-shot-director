# 对白容量与反应预算

## 适用范围

有对白、旁白或 OS 的块必须先估算口播容量。台词可跨镜头，但不得为满足镜头数或块时长删词、改词、换说话人或加快到不自然的语速。

## 容量计算

- 自然对白约 `3.5-5 字/秒`；慢速重音低于 `3.5 字/秒`，只用于明确的情绪顶点；连续超过 `5 字/秒`不得持续超过 `3 秒`。
- 逗号、顿号预留 `0.1-0.3 秒`，句末预留 `0.3-0.6 秒`；关键台词后预留 `0.3-0.8 秒`反应或动作结果。
- `口播时长 = 可发音字数 / 语速 + 标点停顿 + 情绪停顿`。块容量还须包含动作可见过程、转场和末镜无对白尾帧。

## 长台词拆法

先按语义节拍而非字数拆分，优先找：叙述铺垫、信息揭示、情绪转折、目标确认、情绪升华和说完后的反应停顿。可用正反打、过肩、手部或道具反应承接同一条台词，但镜头中的说话人标签必须保持一致。

必须同时满足：

- 合并后的原词逐字等于来源台词，顺序不变；
- 同一条台词中的全部分段都标记原说话人；
- 不同角色、OS 和角色对白绝不合并；
- 每段可自然口播；关键语义节点后留出可见反应；
- 当前块容量不足时增加生成块或重新划分块边界，不以压缩语速解决。

## 五镜头块

`15 秒`块始终有五镜头，但对白不需要一镜一句。用同一台词的语义节拍、听者反应、已发生动作的结果或信息焦点转移组织五镜头；禁止重复凝视或静态空镜补镜头数。最后一个镜头仍要留出 `0.3-0.8 秒`无对白收束。
