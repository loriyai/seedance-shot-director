# 对白容量与反应预算

## 适用范围

有对白、旁白或 OS 的块必须先估算口播容量。台词可跨镜头，但不得为满足镜头数或块时长删词、改词、换说话人或加快到不自然的语速。

## 默认语速档与容量计算

未收到用户特别要求时，统一采用短剧节奏，不额外询问语速：

- `短剧常速`：`4.0-5.2` 个可发音单位/秒，适用于大多数对白、OS、旁白和说明性口播。
- `短剧快节奏`：`4.5-5.8` 个可发音单位/秒，适用于喜剧包袱、连续吐槽、争辩和同一口气的短句；超过 `5.2` 的连续段通常不超过 3 秒。
- `情绪慢速`：`3.3-4.4` 个可发音单位/秒，只用于原文明确支持的哽咽、迟疑、虚弱、庄重宣告或情绪顶点，并在后台登记依据。不得选择该档填满镜头或生成块。

低于所选档位下限属于慢节奏风险，高于上限属于容量风险；两者都必须重排口播区间、改选有依据的语速档或重划块界，不能把镜头空白当成台词时间。

- 逗号、顿号通常只留 `0.1-0.25 秒`，句末或完整语义结束留 `0.3-0.5 秒`；关键台词后的反应另留 `0.3-0.8 秒`，但不能在每个逗号短句后重复添加反应停顿。
- `口播时长 = 可发音字数 / 语速 + 标点停顿 + 情绪停顿`。块容量还须包含动作可见过程、转场和末镜无对白尾帧。
- 可发音字数按实际读法粗估：例如“88”读“八十八”，“50”读“五十”；原文数字仍原样输出，估读形式只进后台。多音读法和字母缩写不能确定时登记为需人工复核，不用原始字符数伪装精确口播时长。
- 上述语速是预算与自动门禁，不是模型生成效果保证。先以人物当前声线读通完整话轮；虚弱、哽咽、狂笑、对话换人和真正的喜剧停顿才按表演加时，不通过统一加速来适应已分配镜头，也不因镜头较长而统一降速。
- 动作与台词的并行/先后关系按 [timing-allocation.md](timing-allocation.md) 计算。OS可覆盖走路、转身等画面动作，不要求人物停步开口；对白与画外对白、OS、旁白分别保留原类型。

## 台词与动作落点

重要对应关系用“边做边说”“说到某词时”“听见后”“说完后”等短语直接编入动作。台词字段列在动作之后不表示最后才发声；动作里的触发词不是第二次口播。道具响应只在它推动承诺、信息或关系时使用，不给每句台词机械配手势。

台词跨镜时先在后台维护完整话轮的连续时间线，再安排画面；切镜、回忆画面、听者反应和焦点转移都不自动新增停顿。同一说话人、同一语气且语义连续的逗号短句默认属于同一口气，不得拆成“一镜一句”后各自起声、收声。跨生成块需落在自然停顿处，特别保护包袱的铺垫与落点，不在“所以……”后机械留出冗长空白。

同一话轮跨两个以上镜头，或长段口播存在节奏风险时，前台按 [prompt-template.md](prompt-template.md) 输出一行“连续口播”，明确全段起止时间和语速档；逐镜台词仍只在实际覆盖的镜头出现一次，不复制全文。

## 长台词拆法

先按语义节拍而非字数拆分，优先找：叙述铺垫、信息揭示、情绪转折、目标确认、情绪升华和说完后的反应停顿。可用正反打、过肩、手部或道具反应承接同一条台词，但镜头中的说话人标签必须保持一致。

必须同时满足：

- 合并后的原词逐字等于来源台词，顺序不变；
- 同一条台词中的全部分段都标记原说话人；
- 不同角色、OS 和角色对白绝不合并；
- 每段可自然口播；关键语义节点后留出可见反应；
- 当前块容量不足时增加生成块或重新划分块边界，不以压缩语速解决。

## 15 秒完整五镜头块

`15 秒`完整块始终有五镜头，但五镜只切画面，不切断声音。一条连续口播可以覆盖两个或更多镜头；用同一台词下的行动、回忆、听者反应、既定动作结果或信息焦点变化组织五个视觉镜头。禁止“一镜一句”、重复凝视或静态空镜补镜头数。最后一个镜头仍要留出 `0.3-0.8 秒`无对白收束。仅最后 `4-<15 秒`尾块可按内容密度使用 1-5 镜；对白容量按其实际时长计算。
