# 声音话轮与容量

## 计量

语速指净发音速度：短剧常速4.0–5.2、短剧快节奏4.5–5.8、情绪慢速3.3–4.4个可发音单位/秒。它们是规划档位，不是演员实测值或生成保证。慢速需哽咽、虚弱、迟疑、庄重等来源依据；不能用来填满时长。

总声音时间 = 净发音时间 + 停顿。不要把含停顿的总速度与净发音档位直接比较。逗号/顿号可估0.1–0.25秒，句末/完整语义可估0.3–0.5秒；关键反应与情绪停顿按来源另记，已计入的停顿不重复相加。

后台记停顿估计与依据。发音单位、数字/年份/编号、外语、字母缩写和情绪读法不确定时用区间并人工复核，不把字符数当精确声音长度。不确定的估时仅警告，明确时间越界、倒序和无授权重叠仍是错误。高于5.2的连续净发音通常不超过3秒，偏离提示复核，不作为没有依据的硬门禁。

## 话轮

话轮具有唯一ID、人物ID、声音类型、完整文本、起止、停顿与来源。相同人同一语气语义连续的话轮可跨镜，切镜不自动换气。动作前后明确“再次开口”、实际沉默、时间跳转或其他人物打断时建立新话轮；不能只凭相同人名合并。

后台使用话轮ID、时间、停顿和语速预算；正文不输出这些制作标签，以自然语言说明实际声音区间。每段声音覆盖其逐镜原文；长话轮可在视觉边界分配片段，各片段依原顺序拼接且不重复。

同一人的声音身份不随OS/旁白变名；类型为对白/OS/旁白。OS不驱动口型，画外对白仍是对白。人物、来源与稳定声线分开记录，不将所有系统角色或具名旁白合并。

## 同步

用边做边说、完成后再说、说到某词时说明动作关系；动作字段只引用短触发词，台词正文只出现在台词字段。不可同时完成的口部/肢体动作遵守物理依赖。

整段口播区间必须与分配台词的视觉镜头相交并匹配，不能把镜头1/2的台词声明到镜头4/5。多个话轮按来源顺序安排；只有来源明确抢话、合说或并发声音才允许重叠，并在后台写依据。

静音尾部不能同时被声音占用。连续剪辑非终结块或剧情硬切按制作配置例外，不以空泛尾帧文字绕过真实时间检查。声音装不下时重划自然块界，不删词、不强制加速。
