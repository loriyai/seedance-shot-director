# 对白容量与反应预算

## 适用范围

有对白、旁白或角色口播的生成块必须执行本规则。无声音文本的块跳过语速计算，但仍须检查画面动作和反应是否超时。

## 基准估算

- 标准对白：约 `3.5~5字/秒`；
- 慢速重音：低于 `3.5字/秒`，只用于明确的金句、威慑或情绪顶点；
- 快速爆发：高于 `5字/秒`，连续使用不超过3秒；
- 可发音字符计入语速，标点另加停顿：逗号/顿号约 `0.1~0.3秒`，句末约 `0.3~0.6秒`；
- 重要台词后保留 `0.3~0.8秒` 的无对白反应时间。

估算式：

```text
口播时长 = 可发音字数 ÷ 语速
对白占用 = 口播时长 + 标点停顿 + 情绪停顿 + 必要反应
```

## 分镜决策

1. 先按自然语速估算对白占用，再从生成块剩余容量中安排动作和镜头；不能反过来压缩台词。
2. 单句超过 `18~24字`时，优先按语义停顿拆成正反打、过肩或反应镜头；不得机械截断原台词。
3. 一句台词若同时承担信息揭示和情绪爆发，应拆成多个镜头，但原文字符和归属必须保持不变。
4. 台词占用超过当前块容量时，增加生成块或调整块边界，不用不自然加速解决。
5. 15秒块仍须满足固定五镜头；对白不足以支撑五镜头时，用视线、动作结果和反应变化补足，不添加新台词。

## 后台检查结果

每条台词记录：原文、字数、语速档、估算占用、所在镜头、是否需要拆镜、是否留出反应。默认只在发现超时、长句或缺少发酵时向用户说明。
