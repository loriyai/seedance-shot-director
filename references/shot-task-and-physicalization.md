# 镜头任务与可视化物理化

## 镜头三任务

每个镜头至少明确承担一项任务：

1. 改变人物情绪；
2. 实质推进动作或空间位置；
3. 增加戏剧压力。

三项都没有的镜头必须删除或合并，不能用重复凝视、重复推镜和空镜凑固定镜头数。

## 镜头最小闭环

每个镜头都要回答：

```text
谁是唯一主目标？
从什么状态开始？
发生了什么可见变化？
变化结果是什么？
镜头结束时留下什么状态给下一镜？
```

动作镜头至少写出“起点 → 过程 → 结果”。复杂动作可补充重心、接触点、受力形变、惯性回收；普通走位不必套完整战斗动力链。

## 抽象词转译

最终提示词不得只写抽象判断，必须落到摄影机能捕捉的事实：

- 愤怒 → 咬肌、下颌、指节、呼吸和视线变化；
- 压迫感 → 光源方向、阴影边界、距离缩短或退路被封；
- 激烈 → 连续的具体动作、接触点、身体位移和环境反馈；
- 速度快 → 明确轨迹、方向、运动结果和被带动的衣发/尘雾；
- 高级/震撼/电影感 → 构图、景别、焦点、光线、材质和声音事实。

## 表演限制

- 情绪镜头每次只设一个主要表演通道，最多一个辅助变化；
- 不用连续堆叠皱眉、抿嘴、转头、握拳等动作替代情绪递进；
- 结尾必须锁定可见状态，不以“恢复正常”或无理由黑屏结束；
- 不为满足固定镜头数新增剧情，只增加已有事件的观察、反应或结果展示。
