# 镜头任务与可视化物理化

## 最小闭环

每个镜头在后台须能回答：唯一主目标是谁或是什么、当前画面是什么、从何状态开始、发生什么可见过程、结果如何、结束时给下一镜留下什么状态。正文把这些答案合并为一条“画面与动作”，不逐项复述问题或字段名。镜头可以推进事件、揭示信息、呈现反应，也可以让观众读完持续状态或离场余韵；不强制每镜新增变化，但须有观看价值。

动作写成“起点 → 过程 → 可见结果”。复杂动作可补接触点、重心、惯性和环境反馈；普通动作保持简洁，不虚构额外情节。

## 人物表达

- 台词、动作与表演使用角色全名或唯一身份：`陈默低头`、`吴天德将卷宗按在桌案上`。多人镜头禁止用“他”“她”“对方”“某人”描述人物动作或发言。
- 情绪落到当前景别和观察角度能看见的变化。近景可读眼神与面部，远景或背影优先步态、肩背和重心。一个镜头选择一个主表演通道，最多一个辅助变化；表演强度服从剧情，不统一压成微表情。
- 不重复堆叠皱眉、抿嘴、转头、握拳或凝视。再次表达同类情绪时须有持续作用、视角价值或结果，不为镜头数量强造情绪升级。
- 互动反应必须有可追溯触发：台词、动作、新信息或动作结果。人物可在关键信息出现时提前局部反应，但不得提前知道尚未说出或发生的内容。
- 优先沿用已建立的动作或道具表现反应：动作短暂停住、力度改变、节奏改变、视线改向或恢复动作。不得为了增加生动度凭空添加事务、道具、隐情或关系。
- 每个情绪镜头可写“触发 → 可见回应 → 结束时残留状态”；残留状态应进入镜头结束状态或块出口，避免切镜后人物无理由归零。
- 视线必须写明落点和变化原因；“复杂眼神”“目光深沉”等抽象表述不能单独承担表演信息。

## 环境与道具

环境细节必须与当前场景相关、可见或可听，并服务氛围、动作或空间。每镜只写少量关键动态，例如荒草随风轻摆、灯笼受脚步气流轻晃、粥面微弱热气、脚步带起尘土或衣摆发丝受风微动。

环境动态不能替代人物主动作。道具要写明在画面中的位置、被谁接触、发生何种状态变化以及镜头结束时的位置；不得瞬移或无故出现。

## 时间与可见性

- 动作与台词有先后时写“完成……后再说”；同时发生时写“边……边说”，必要时指定在某个台词关键词处取物、抬眼或停步。动作不能一律排在台词之前，也不为每句话配一个手势。
- 用秘籍呼应原文提到的秘籍等细节可以在受控范围内补足；不额外制造道具来历、功能、内容或剧情。首次取出后记录去向，后续不反复从怀中掏出同一本书。
- OS 与持续行动可以并行，明确是内心画外音，不要求人物开口对口型；画外对白与内心 OS 不混同。
- 后入场人物仅在对应镜头写“起始画外/被遮挡 → 从哪里进入 → 停在哪里”；听见或看见入场者之后才反应。不得在块头提前执行入场动作。
- 动作完成后的停顿须有具体承载状态和节拍理由，允许有意义的静止或固定摄影机，不靠新增动作或风吹草动硬凑时间。

## 抽象词转译

“愤怒”“压迫”“速度快”“电影感”等判断必须转成画面可捕捉的表演、距离、光线、构图、受力、轨迹、焦点或声音事实。仅写“激烈”“压迫感强”“镜头有电影感”视为信息不完整。
