# 风格配置

首次需要用户选择风格时，完整、原样展示以下三个选项，不附通俗解释，不另拆人物表现形式与美术风格：

①3D国风动漫,暗黑武侠/超写实仙侠风格
②3D国风动漫，眷思量风格，东方奇幻唯美风格
③自定义

用户已明确风格时直接记录，不重复询问。自定义接受文字或实际参考素材，只补问影响执行的含混处。项目选择不写入技能安装目录。

编译时按当前选择提取必要视觉特征：选项①可使用低饱和冷灰、土赭与真实物体受力；选项②可使用清透色彩、柔和层次及自然衣发动态。角色核心造型由用户设定或实际素材决定，不擅自补写外貌、发型、体型和服装款式。风格不改变剧情、声音身份、信息顺序，也不锁死每场光线或语气。

原文明示的衰老、衣衫褴褛、伤势等叙事状态在对应镜头呈现；人物栏只列姓名、必要阶段和实际素材绑定。仅在用户提供时写真实素材标识，不虚构引用。
