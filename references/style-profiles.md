# 风格配置

风格与目标时长、是否输出资产列表在同一次询问中给出，只问这三项；完整剧本分析完成后不再追加其他问题。

首次需要用户选择风格时，完整、原样展示以下三个选项，不附通俗解释，不另拆人物表现形式与美术风格：

①3D国风动漫,暗黑武侠/超写实仙侠风格
②3D国风动漫，眷思量风格，东方奇幻唯美风格
③自定义

用户已明确风格时直接记录，不重复询问；一次选择在本任务内复用，不逐段重问。自定义接受文字或实际参考素材，只补问影响执行的含混处。项目选择不写入技能安装目录。

每个生成块的风格行必须原样包含用户选定的完整风格文字，选项①固定写作`3D国风动漫,暗黑武侠/超写实仙侠风格`，不得用色彩、材质或质感概括替换。需要时可在原文之后另写场景视觉补充，但不能改写或删去选项原文。角色核心造型由用户设定或实际素材决定，不擅自补写外貌、发型、体型和服装款式。风格不改变剧情、声音身份、信息顺序，也不锁死每场光线或语气。

原文明示的衰老、衣衫褴褛、伤势等叙事状态在对应镜头呈现；直投“人物：”只列角色名或“无”，阶段与素材绑定保留在后台或独立素材行。仅在用户提供时写真实素材标识，不虚构引用。
