# 局部修改流程

## 适用场景

当用户基于最近一次结果，明确指定生成块编号和一个或多个镜头编号并提出修改要求时，使用局部修改流程。若只有一个生成块，也可以省略生成块编号。

## 修改原则

1. 读取最近一次完整生成块作为底稿，识别用户指定的生成块编号、镜头编号和具体修改要求。
2. 修改前在后台建立三张清单：
   - `CHANGE`：用户明确要求改变的镜头和字段。
   - `PRESERVE`：未被要求改变的台词、人物、素材绑定、场景、动作结果、时长、光线、声音和其他镜头。
   - `ADJACENCY`：修改是否影响前一镜出口、后一镜入口、轴线、焦点、道具位置或时间端点。
3. 每次局部修改确定一个主修改目标。只替换 `CHANGE` 中的相关内容；`PRESERVE` 必须保持原文不变，`ADJACENCY` 只做维持连续性所需的最小调整。
4. 若修改多个镜头，逐个完成修改，再检查这些镜头与相邻镜头的景别、机位、运镜、构图、焦点和空间连续性；如改变时长，重新校正整块总时长，但不改变未指定镜头的叙事内容。
5. 修改后完整输出被修改生成块的全部内容，保留生成块序号，不得只输出修改后的镜头；其他未指定生成块不重复输出，除非用户要求全部重发。
6. 如果只收到镜头编号，没有收到具体修改要求，先要求用户补充；如果缺少可作为底稿的完整生成块，先要求用户提供该生成块。
7. 修改完成后更新 [generation-block-ledger.md](generation-block-ledger.md) 中对应块的状态为“局部修改”，并重新检查该块与相邻块的入口/出口状态。

## 修改层级判断

- **字段级修改**：只改变景别、机位、运镜、构图、焦点、表演、环境动态或声音中的少量字段，使用局部修改。
- **镜头重切**：修改导致动作起点、过程和结果无法在原镜头时长内闭环，或需要改变相邻切镜逻辑时，重切指定镜头边界。
- **生成块重划**：修改同时改变台词归属、主要场景、关键动作结果、时间跳转或多个镜头时长结构时，不再伪装成局部字段修改；明确按生成块重划处理，但仍保留不受影响的来源节拍。

## 可改内容

可修改指定镜头的：

- 景别
- 机位
- 运镜
- 构图
- 焦点
- 动作描述
- 环境动态
- 转场
- 音效/环境音
- 表演细节

## 不可改内容

未被要求修改的：

- 角色
- 场景
- 台词
- 旁白
- 时间节点
- 未被要求修改的音频字段和台词声线
- 全局场景描述
- 其他镜头
- `@素材`引用及其对应资产描述

未被要求修改的 `@素材`名称和状态版本必须逐字保持；改变机位、构图或焦点不构成更换素材的理由。

## 输出格式

修改完成后仍采用完整生成块格式：

```text
生成块1
[修改后的完整提示词，包含未修改的全部内容]
```
