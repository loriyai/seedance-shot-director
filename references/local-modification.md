# 局部修改流程

## 适用场景

当用户基于最近一次结果，明确指定生成块编号和一个或多个镜头编号并提出修改要求时，使用局部修改流程。若只有一个生成块，也可以省略生成块编号。

## 修改原则

1. 读取最近一次完整生成块作为底稿，识别用户指定的生成块编号、镜头编号和具体修改要求。
2. 只替换指定镜头的相关内容；未指定镜头必须保持原文不变。
3. 若修改多个镜头，逐个完成修改，再检查这些镜头与相邻镜头的景别、机位、运镜、构图、焦点和空间连续性；如改变时长，重新校正整块总时长，但不改变未指定镜头的叙事内容。
4. 修改后完整输出被修改生成块的全部内容，保留生成块序号，不得只输出修改后的镜头；其他未指定生成块不重复输出，除非用户要求全部重发。
5. 如果只收到镜头编号，没有收到具体修改要求，先要求用户补充；如果缺少可作为底稿的完整生成块，先要求用户提供该生成块。
6. 修改完成后更新 [generation-block-ledger.md](generation-block-ledger.md) 中对应块的状态为“局部修改”，并重新检查该块与相邻块的入口/出口状态。

## 可改内容

可修改指定镜头的：

- 景别
- 机位
- 运镜
- 构图
- 焦点
- 动作描述
- 环境动态
- 转场
- 音效/环境音
- 表演细节

## 不可改内容

未被要求修改的：

- 角色
- 场景
- 台词
- 旁白
- 时间节点
- 未被要求修改的音频字段和台词声线
- 全局场景描述
- 其他镜头
- `@素材`引用及其对应资产描述

## 输出格式

修改完成后仍采用完整生成块格式：

```text
生成块1
[修改后的完整提示词，包含未修改的全部内容]
```
