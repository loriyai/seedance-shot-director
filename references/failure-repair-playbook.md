# 常见失败与最小修复

## 使用原则

在 P0/P1 质检发现典型风险时，先定位失败字段，再做最小范围修复。不得用新增剧情、改写台词、加速口播、重复镜头或堆叠限制词掩盖问题。

## 症状与修复顺序

| 症状 | 常见原因 | 最小修复顺序 |
|---|---|---|
| 人脸、发型或服装漂移 | 缺少参考素材，或临时状态与人物身份混写 | “人物：”恢复为纯角色名，精确 `@素材`绑定放独立素材行或后台；没有素材时不补写外貌，也不承诺精确复现；逐镜只写来源明确的剧情状态变化 |
| 多人融合、无故增删人物 | 多人等权描述，没有唯一主目标和层次 | 固定出场人数；提高主目标占比；其他人物退入明确中后景；分别写全名、位置和动作 |
| 动作悬空或没有结果 | 单镜动作过长，只写意图或过程 | 缩短动作链；补齐起点、关键过程、接触点和可见结果；必要时重切镜头边界 |
| 运镜混乱或摄影机命令冲突 | 同镜包含多个方向、速度、焦点或终点 | 保留一个主运镜、一个速度变化和一个终点；删除与镜头任务无关的摄影词 |
| 道具瞬移、换手或状态复原 | 未记录持有人、接触过程和出口位置 | 补齐道具起始位置、接触者、状态变化和镜头结束落点；同步相邻镜头入口 |
| 跳轴、左右反转或空间不明 | 缺少固定锚点、朝向或摄影机侧别 | 恢复人物连线、摄影机所在侧和固定空间锚点；必要时加入有动机的过渡镜头 |
| 台词漏词、重词、错归属 | 对白映射不完整或容量超限 | 对照来源逐字修复映射；恢复说话人；重新分配时长；仍超限则新增生成块 |
| 台词与反应错位 | 反应提前获知信息或缺少口播后窗口 | 将反应绑定到明确词句或动作触发；为关键信息保留可见回应和尾部停顿 |
| 连续短句被说得过慢 | 先按镜头切台词，在标点处重复留气口，或为填满15秒主动降速 | 先恢复完整话轮的连续声音轨；删除切镜新增停顿；只有锁定来源已有标点或经程序核实的换行规范化逗号可作为跨镜边界；画面、回忆和反应改为并行 |
| 同一话轮“一镜一句” | 把五镜误解成五段声音，镜头边界驱动起声和收声 | 五镜只切画面；除经程序核实的换行规范化逗号外，无标点的连贯词句完整留在同一镜；后台用同一话轮ID绑定整句声音时间、人物、类型与停顿，正文逐镜只保留一次规范化来源覆盖，不输出中间镜声音安排 |
| 优化后块数异常增加 | 把分镜动作全部当作串行动作并逐项累加 | 将动作恢复为默认并行；只有原文先后依据或物理依赖可保留串行；按声音轨重新计算最少必要块数 |
| 长评价配回忆仍显拖沓 | 为每个回忆镜头分配独立一句和停顿，把画面时长误加到口播时长 | 让评价声音连续覆盖回忆画面；只在锁定来源原标点或经程序核实的换行规范化逗号处自然换气；用回忆变化丰富画面而不延长声音轨 |
| 同场景跨时间不明显 | 沿用同一 `time_id`，或只写时间说明 | 保留地点 `scene_id`、改用新的 `time_id` 并拆块；前块末镜和后块首镜各留至少1秒无对白画面；新块显式写来源支持的环境、年龄、服装、道具、光线或空间状态变化，不替用户设计转场 |
| 剧情内文字乱码或多出文字 | 没有给出精确文本、载体和文字边界 | 仅保留来源原文；写清载体、位置、字形、占比和可读时长；其他表面保持无字 |
| 提示词执行不完整 | 字段重复、装饰词过多、多个目标争夺注意力 | 先删除重复信息和泛化电影词，再删装饰性材质与次要环境动态；保留剧情、连续性和镜头执行字段 |
| 局部修改扩大化 | 没有明确修改集和保持集 | 建立 `CHANGE / PRESERVE / ADJACENCY` 三清单；只改指定字段；受影响相邻状态单独修复 |
| 人物提前出现或提前变脸 | 块头混入未来动作，只写双人镜头终点 | 将块头改为稳定事实；对应镜头写画外/遮挡起点、入场路径、停点；看到或听到后再反应 |
| 人物先做完动作才说话 | 没写同步关系，把动作与对白串行化 | 写明边做边说或某关键词处动作；按重叠时间重算，不简单累加 |
| 背影读不出眼神或回望 | 表演和观察角度冲突 | 背影改用肩背、步态；需要看脸时采用可读的侧后角度或另一个编号镜头 |
| 动作后空等、离场仓促 | 平均分秒或把尾部余量当完整表演预算 | 先给关键节拍自然时间；停顿写明承载状态；容不下时重划块界，不新增动作凑数 |
| 标为五镜但实际切了更多次 | 一个编号内写反打、插镜、再切 | 将真正切换分配给独立编号，连续运镜写起终点；完整 15 秒块仍只有五镜 |
| 实体“切到/反打”被误判切镜 | 动作词与摄影术语共用宽匹配 | 摄影字段继续硬拦截；动作字段只有明确镜头、画面、机位、视角或景别语境才硬拦截，菜刀切到指尖或人物反打等保留为动作并完成警告复核 |
| 单镜超过5秒 | 为省镜头延长站立说话、凝视、慢推或复杂动作链 | 把镜头重切为各自有观看重点的连续镜头；15秒块在五到七镜内重排，无法同时满足时重划来源生成块 |
| 块内出现大段无口播 | 为凑满 15 秒拉长已有动作 | 先按自然内容取整块时长（`ceil` 后再看留白），余量只用末镜余韵承载；仍超 `max(1.0, 留白需求)+1.0` 秒就把相邻块内容借进来重排 |
| 分批首尾漏留无对白画面 | 规划只读取本批内部相邻块 | V5填写`boundary_context`的前后相邻`scene_id/time_id`；全片真实边缘才用`null`，由编译器统一计算首尾留白与自动收尾 |
| 同场连续块出现人工停顿 | 默认把每个块都按独立收束处理 | 使用自动收尾；同一连续时空且有后继块时连续剪辑，不额外加入0.3–0.8秒尾静默，真正末块再独立收束 |
| 为满足声音分句虚构声音 | 把输出栏误解为必须存在可听声响 | V5中块级与镜级都无依据声音时省略`ambient_effects/effects`，由编译器输出“本镜静默；”；不得与实际音效混用 |
| 外语或型号空格被吞并 | 覆盖校验删除了所有空白 | 只去除每行首尾排版缩进，保留行内空格；未经审阅确认的任何空格增删都按正文不一致处理 |
| 独立生成块无法复现旧构图 | 依赖未提供的上一块画面 | 前台写足本块可见起点；只有实际提供参考帧才引用，不在后台假设或设计跨块匹配剪辑 |
| 黑暗画风下所有表演都低沉 | 把美术基调当成情绪模板 | 保持视觉风格，按原文分别设计豪言、尴尬、自嘲、温情或情绪爆发 |
| 台词校验看似通过却漏段 | 源稿有未归属引号、混排标注或未闭合引号 | 查看覆盖警告，人工完成来源台账；展示文字单独核对，不能将局部解析当全量覆盖 |
| 话轮时间反复超档或被拦截 | 可发音单位与净发音语速靠手算 | 起草前跑 `scripts/plan_voices.py --text` 取单位、各档可行区间与合法切分点，按建议区间回填，不逐轮试错 |
| 骨架漏句、调序或单位不符 | 只在收尾才做覆盖比对 | 骨架定稿后跑 `scripts/plan_voices.py --plan`；漏句、调序与可发音单位总量在写镜头前清零 |
| 同场景相邻块背景参照物漂移 | 每块各写一份场景描述 | 每个 `scene_id` 只维护一份场景包（抬头、七项设计、底声），其余块逐字复用背景层措辞 |
| 巨型规划写入失败被整份重发 | 一次性提交全部块 | 按 3–4 块一批分次写入并即时 `check-block`，失败只重发该批 |

## 回退层级

1. **字段修复**：只改当前镜头的失败字段。
2. **镜头重切**：同一镜头两次字段修复仍无法形成动作、时长或空间闭环时，重切镜头边界。
3. **生成块重划**：对白容量、多场景或时间跳转无法容纳，或声音轨明显稀疏且可并入相邻来源节拍时重新划块；采用最少必要块数，不因优化动作变多扩块。
4. **用户追问**：缺少关键叙事事实，且任何技术修复都会改变剧情时才追问。

每次回退都保留未受影响的来源映射、台词、人物、道具和相邻块状态。
