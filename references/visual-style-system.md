# 稳定视觉系统

## 稳定视觉层

每个生成块在块标题下一行、人物与场景信息之前写一句稳定视觉提示。该句由“动态美术方向＋固定执行约束”组成：动态部分按 [style-profiles.md](style-profiles.md) 的当前选项转译，固定部分只约束生成质量、声音和剧情外文字，不得写死默认风格。

```text
<当前已选风格转译后的中文可执行视觉特征>；人物与材质表现统一，动作符合物理，表演自然连贯，镜头衔接清晰；环境声真实，无背景音乐；不生成剧情外文字、剧情外界面或水印；保留原剧情明确要求的文字与界面。
```

最终输出必须用当前风格最关键的中文可执行特征替换尖括号内容，可从色彩、材质、光影、人物塑造、动作审美和镜头气质中选择必要项；不得保留占位符，不得直接复制作品名替代可执行特征。该层不包括时长、画幅、固定场景光线、固定运镜、固定景深或固定特效。逐镜只补充完成当前叙事所需的摄影与光影变化，不重复“电影级”“真实材质”“前中后景”等泛化描述。

## 特效与文字边界

- “高精度粒子流体特效”仅在原剧情明确需要雨、火、烟、爆炸、真气或血雾时启用；不得作为全局默认。
- “不生成剧情外文字、剧情外界面或水印”不限制剧情明确出现的墓碑、书页、卷宗、牌匾、字幕或系统界面。描述文字内容时只保留原文给出的内容，不补写界面文案。
- 没有剧情依据时，禁止新增字幕、水印、旁白文字或界面文字。

## 场景光影变量词表

稳定层不固定光线。连续场景在镜头变量层选择一组清晰词并保持一致：

- 荒山白天：冷硬日光，低饱和土色，清晰短阴影。
- 陈府寿宴：暖灯笼主光，院外冷色补光，人物面部暖亮、门外留冷影。
- 系统空间：黑色虚空，古书淡金主光，背景无建筑反射。
- 紫衣门夜战：固定月光方向，真气光只照亮接触区域。

每场景再按需要写主光方向、软硬、色温、阴影边界、轮廓光、环境反射和特效光；同一连续场景不能无依据混用多套模糊冷光描述。
