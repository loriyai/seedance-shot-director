# 稳定视觉系统

## 稳定视觉层

每个生成块在可复制正文开头写一段短句，统一渲染质感；用户指定风格时按 [style-profiles.md](style-profiles.md) 微调美术方向：

```text
UE5级光线追踪影视写实渲染，电影级画质，空间层次清晰，构图有前中后景，景深随主体切换，运镜连贯自然，材质细节真实；人物肤色自然，发丝、布料、皮肤细纹清晰，眼神自然聚焦，眨眼和呼吸自然，微表情细腻，衣袂随环境风力轻微变化；有环境音效，无背景音乐，无额外字幕、水印和界面文字。
```

该层不包括时长、画幅、固定场景光线、固定运镜或固定特效。每个镜头另写具体景别、机位、运镜、焦点、景深和本场景光影。

## 特效与文字边界

- “高精度粒子流体特效”仅在原剧情明确需要雨、火、烟、爆炸、真气或血雾时启用；不得作为全局默认。
- “无额外文字”允许剧情明确出现的墓碑、书页、卷宗、系统界面等文字。描述文字内容时只保留原文给出的内容，不补写界面文案。
- 没有剧情依据时，禁止新增字幕、水印、旁白文字或界面文字。

## 场景光影变量词表

稳定层不固定光线。连续场景在镜头变量层选择一组清晰词并保持一致：

- 荒山白天：冷硬日光，低饱和土色，清晰短阴影。
- 陈府寿宴：暖灯笼主光，院外冷色补光，人物面部暖亮、门外留冷影。
- 系统空间：黑色虚空，古书淡金主光，背景无建筑反射。
- 紫衣门夜战：固定月光方向，真气光只照亮接触区域。

每场景再按需要写主光方向、软硬、色温、阴影边界、轮廓光、环境反射和特效光；同一连续场景不能无依据混用多套模糊冷光描述。
