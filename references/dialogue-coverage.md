# 台词与剧情覆盖

## 后台台账

生成前逐段记录：

```text
来源节拍：
原文台词：
说话人：
类型：角色对白 / OS / 旁白
场景：
时间：
涉及人物：
涉及道具：
生成块编号：
镜头编号：
入口状态：
出口状态：
对白容量：
质检状态：
```

台词归一化仅应用 [dialogue-normalization.md](dialogue-normalization.md) 允许的换行排版变换。台账保留原文和归一化文本，不能只保留其中之一。

## 输出前逐条检查

- 每个原文事件、动作说明、时间跳转和台词均进入一个生成块和镜头。
- 每句台词出现一次且只出现一次；归一化比较后，输出台词按原顺序逐字覆盖原文。
- 台词说话人正确，角色对白、OS 与旁白相互区分。
- 关键动作有可见结果；动作说明不遗漏。
- 时间跳转有视觉衔接和变化依据。
- 输出没有新增剧情、人物关系、反转或结局。

发现遗漏、重复、顺序变化、说话人错配或新增叙事，停止输出并重划生成块或镜头。
