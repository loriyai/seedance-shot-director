# 生成块工业台账

## 用途

为一段文案拆出的多个生成块建立可追踪记录，使每个块可以独立生成、复查和后续单独优化。

## 每块记录

```text
生成块ID：GB-001
目标时长：15秒或30秒
来源节拍：原文中被本块承载的事件范围
块目标：本块必须完成的一个主要视觉目标
涉及资产：角色、场景、道具及其稳定锚点
入口状态：位置、朝向、视线、手部道具、动作进度、光线环境
出口状态：位置、朝向、视线、道具、动作结果、情绪和环境
镜头数量：15秒=5；30秒按事件密度决定
对白容量：原文台词、估算占用、反应余量
专项路由：情绪 / 空间 / 战斗 / 其他，按需加载
质检状态：P0 / P1 / P2 / 通过
```

## 块间一致性

- 下一块入口状态必须与上一块出口状态一致，除非明确写出跳转依据；
- 每个块重复自己的固定风格、固定规则和资产锚点；
- 原文节拍只能归属一个块，状态锚点可以在相邻块重复；
- 后续修改以 `生成块ID + 镜头编号` 定位，未指定的块和镜头不重写。

## 台账状态

- `草稿`：已分块，尚未完成镜头闭环；
- `待质检`：提示词已完成，等待检查；
- `P1修复中`：存在容量、动作或连续性结构问题；
- `通过`：可直接复制投喂；
- `局部修改`：仅指定块或镜头发生变更，需重新检查相邻衔接。
