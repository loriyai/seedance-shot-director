# 生成块工业台账

## 用途

后台台账把原文节拍逐项映射到生成块与镜头，防止事件、动作、台词、时间跳转在拆块时遗漏、重复或错配。它不默认展示给用户。

## 唯一规划

以下字段描述需要保留的信息，不要求模型另写一套表格。实际按 [unified-plan.md](unified-plan.md) 写一次结构化规划；脚本生成的台账直接包含该规划与检查结果。声音正文只写在 `voices[].text`，镜头引用话轮ID及可选字符范围；节拍、人物/场景稳定事实和入口/出口各记一次。可见执行信息放镜头字段，额外导演依据按需放 `notes`，不为无关字段填空。

## 段落总表

完整剧本首次处理时建立 [long-script-index.md](long-script-index.md) 的人物关系、场景、关键道具、时间线与伏笔索引；来源修订后增量更新，版本恢复按 [project-state.md](project-state.md)。后续分段只读取当前段落及必要的前后状态；局部修改只更新指定块和相邻衔接。

原文台词：
说话人：
类型：角色对白 / OS / 旁白 / 仅展示文字 / 动作事件
场景：
时间：

涉及道具：
生成块编号：
镜头编号：
入口状态：
出口状态：

台词保留原文和按 [dialogue-normalization.md](dialogue-normalization.md) 得到的归一化口播文本；原文永远是覆盖比较的依据。

## 每块记录

```text
生成块ID：GB-001
目标时长与画幅：15秒，16:9
来源节拍：原文事件与动作范围
块目标：本块的一个主要视觉目标
人物：身份、年龄阶段、外观、服装、当前状态；首次可见镜头、画外/遮挡与入场触发
场景：空间锚点与光影方案
氛围与站位：环境情绪、世界内相对位置、朝向/视线、道具、轴线；画面前中后景按各镜机位另核对
入口状态：位置、朝向、视线、手部道具、动作进度、光线环境
出口状态：位置、朝向、视线、道具、动作结果、情绪和环境
镜头数量与时间轴：15秒完整块=5镜；最后一块/最后两块可按实际时长重排，短于15秒=1-5镜；30秒通常8-12镜；各镜起止时间
对白容量：原文、说话人、类型、数字实际读法、估算占用、语义节拍、所在镜头、尾部反应
口播链：话轮ID、人物ID、声音类型、完整文本、起止、净发音语速档、停顿预算与依据、跨越镜头、并发来源依据；同人隔动作再次开口另建ID
执行时间：主表演预算、串行动作区间、对白与动作重叠区间、关键语词同步点、必要停顿
动作并行性：每个来源动作与增强动作标为并行/必须串行；必须串行时记录原文先后依据或物理依赖
可见性：摄影机观察角度、表演通道是否可读、入场路径与停止位置、反应触发顺序
画面文字：逐字内容、载体、首次出现/持续/替换、可读区间，与朗读内容分开
转场：编号镜头之间的剪辑动机、方式；跨生成块匹配计划及实际提供的参考素材
专项路由：情绪 / 空间 / 战斗 / 其他，按需加载
质检状态：草稿 / 待质检 / P0阻断 / P1修复中 / P2优化 / 通过 / 局部修改
```

## 覆盖与连续性

- 每个来源节拍保留唯一ID，只发生一次；其过程或话轮可以映射到多个镜头的有序片段。用片段范围检查覆盖，不能把跨镜呈现误判为重复事件；为连续性重述状态不算重演。
- 每句台词出现一次且只出现一次，原词顺序、说话人和类型不变；合并后逐字覆盖原台词。
- 下一块入口与上一块出口一致。发生时间/空间跳转时，登记转场方式、可见衔接和环境/人物/服装/道具/季节等变化。
- 同一口播链跨镜时保持唯一连续时间段；镜头切换、回忆或反应画面不写成新的停顿。受控优化动作默认并行，只有来源先后关系或物理依赖可标为必须串行并增加时长。
- 任何块或镜头的局部修改后，重查该块台词映射、出口状态以及相邻块入口。
- 短尾优先合并或联合调整最后两块，按 generation-block-splitting.md 完整收尾；仅用户明确同意暂存未完稿时登记未使用，不将其计为已完成。

完整台账由编译器生成并在后台保留，不再人工重写。前台首镜承接必要起点，人物表只简注首次可见镜头，具体入场、同步动作和文字变化写进相应镜头，不增添一套重复标签。原文存在无说话人引号段或“念/不念”等混排时，先人工核对归属和朗读边界；自动脚本只能校验已识别部分，不据此宣称全稿覆盖。
