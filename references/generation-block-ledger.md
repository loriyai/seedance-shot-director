# 生成块台账（编译产物）

## 原则

台账用于防止来源节拍、台词、时空和动作结果在拆块时遗漏、重复或错配，但它不是模型要手写的第二套规划。

新任务只写 [unified-plan.md](unified-plan.md) 的 V5 规划。`compile_plan.py` 把原规划、来源/配置/候选摘要、硬检查诊断、聚合警告和语义复核状态共同写入 `ledger.json`。不先写本文字段表，也不把直投正文反向抄回台账。

## 信息的唯一位置

- 来源节拍只在 `beats` 登记；同一节拍的过程可映射到多镜，但事件只发生一次。
- 整句台词只在 `voices[].text` 登记；镜头只引用话轮 ID 和必要的字符范围。
- 人物姓名、阶段、素材、画外与可见范围只在块级 `characters` 登记；直投 `人物：` 只显示姓名或“无”。
- 稳定场景底声只在 `ambient_effects` 登记一次；镜头 `effects` 只记变化。
- 简单块入口/出口从首末镜动作派生；只有镜头动作未表达的连续性信息才显式写 `entry/exit`。
- 时空身份使用 `scene_id/time_id`；批次外部相邻状态只在 `boundary_context` 写一次。
- 额外来源依据、观众/人物知情差或导演复核说明只在确有必要时放 `notes`，不为空模板填充。

## 覆盖与连续性

- 台词片段按原序拼接必须完整覆盖规范化话轮；跨镜只用来源标点或可反查换行逗号。
- 下一块入口与上一块出口在人物位置、朝向、道具、动作进度和来源支持的环境状态上一致。
- 地点变化或同场景跨时间会更换时空身份，并为前尾、后首各保留至少 1 秒无对白画面；不登记用户尚未决定的后期转场方法。
- 任何局部修改后，更新该块的台词映射、出口状态和相邻入口，不重写无关块。

完整剧本的人物关系、场景、关键道具、时间线和伏笔属于 [long-script-index.md](long-script-index.md) 的全局索引，不在每个生成块台账中重复全量复制。
