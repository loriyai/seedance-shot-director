# 生成块工业台账

## 用途

后台台账把原文节拍逐项映射到生成块与镜头，防止事件、动作、台词、时间跳转在拆块时遗漏、重复或错配。它不默认展示给用户。

## 段落总表

完整剧本首次处理时建立一次人物、场景、道具和时间线档案。后续分段只读取当前段落及必要的前后状态；局部修改只更新指定块和相邻衔接。

```text
来源节拍：
原文台词：
说话人：
类型：角色对白 / OS / 旁白 / 仅展示文字 / 动作事件
场景：
时间：
涉及人物：
涉及道具：
生成块编号：
镜头编号：
入口状态：
出口状态：
对白容量：
质检状态：
使用状态：已生成 / 暂存未使用
```

台词保留原文和按 [dialogue-normalization.md](dialogue-normalization.md) 得到的归一化口播文本；原文永远是覆盖比较的依据。

## 每块记录

```text
生成块ID：GB-001
目标时长与画幅：15秒，16:9
来源节拍：原文事件与动作范围
块目标：本块的一个主要视觉目标
人物：身份、年龄阶段、外观、服装、当前状态；首次可见镜头、画外/遮挡与入场触发
场景：空间锚点与光影方案
氛围与站位：环境情绪、世界内相对位置、朝向/视线、道具、轴线；画面前中后景按各镜机位另核对
入口状态：位置、朝向、视线、手部道具、动作进度、光线环境
出口状态：位置、朝向、视线、道具、动作结果、情绪和环境
镜头数量与时间轴：15秒完整块=5镜；最后4-<15秒尾块=1-5镜；各镜起止时间
对白容量：原文、说话人、类型、数字实际读法、估算占用、语义节拍、所在镜头、尾部反应
口播链：链ID、说话人/类型、完整口播、起止时间、语速档、原标点换气点、跨越镜头、切镜新增停顿=否
执行时间：主表演预算、串行动作区间、对白与动作重叠区间、关键语词同步点、必要停顿
动作并行性：每个来源动作与增强动作标为并行/必须串行；必须串行时记录原文先后依据或物理依赖
可见性：摄影机观察角度、表演通道是否可读、入场路径与停止位置、反应触发顺序
画面文字：逐字内容、载体、首次出现/持续/替换、可读区间，与朗读内容分开
转场：编号镜头之间的剪辑动机、方式；跨生成块匹配计划及实际提供的参考素材
专项路由：情绪 / 空间 / 战斗 / 其他，按需加载
质检状态：草稿 / 待质检 / P0阻断 / P1修复中 / P2优化 / 通过 / 局部修改
```

## 覆盖与连续性

- 每个原文事件、动作说明、台词、OS、旁白和时间跳转只能归属一个生成块与镜头；为连续性重复的状态锚点不算重复事件。
- 每句台词出现一次且只出现一次，原词顺序、说话人和类型不变；合并后逐字覆盖原台词。
- 下一块入口与上一块出口一致。发生时间/空间跳转时，登记转场方式、可见衔接和环境/人物/服装/道具/季节等变化。
- 同一口播链跨镜时保持唯一连续时间段；镜头切换、回忆或反应画面不写成新的停顿。受控优化动作默认并行，只有来源先后关系或物理依赖可标为必须串行并增加时长。
- 任何块或镜头的局部修改后，重查该块台词映射、出口状态以及相邻块入口。
- 最后剩余内容不足 4 秒时，逐字登记为“暂存/未使用”，保存预计时长与规定提示；该内容不分配生成块编号和镜头编号，也不计入本次已生成覆盖率。

完整台账只在后台保留。前台首镜承接必要起点，人物表只简注首次可见镜头，具体入场、同步动作和文字变化写进相应镜头，不增添一套重复标签。原文存在无说话人引号段或“念/不念”等混排时，先人工核对归属和朗读边界；自动脚本只能校验已识别部分，不据此宣称全稿覆盖。
