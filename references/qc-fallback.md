# 质量检查与回退

## 质量检查

输出前静默检查以下内容：

- 镜头数是否符合规则：15 秒必须 5 个，30 秒通常 8-12 个且由剧情决定。
- 短分段是否已经按事件容量拆成合理的 N 个生成块，而不是强行压成一个块。
- 每个生成块是否都重复包含固定风格、固定规则、角色锚点、场景锚点和入口状态。
- 原文节拍是否全部覆盖，且没有被重复、遗漏或放入无法容纳的块。
- 时长是否动态分配且总和正确。
- 镜头时间端点是否递增、连续、无重叠，且没有残留占位符。
- 是否出现角色漂移、场景跳跃、道具漂移。
- 是否出现空泛、重复、偷懒式描述。
- 是否明确写出机位、运镜、景深、光线、音效和表演细节。
- 是否保持风格统一和空间连续性。
- 是否避免新增关键剧情、反转、人物关系或结局。
- 单个生成块是否自包含，脱离上下文仍有风格、画幅、总时长、角色、场景和连续性约束。
- 每个生成块是否具有可描述的出口状态，并与下一块入口状态一致；若有跳转，是否写明跳转依据。
- 每个生成块是否按三层提示词组织：固定层完整重复、变量层只写本块内容、负面层按风险加载。
- 每个镜头是否至少有一项明确任务，且具备唯一主目标、起始状态、可见变化、结果和结束状态。
- 每次切镜是否有动作、反应、景别、视线、遮挡或动势动机；相邻镜头是否保持焦点可追踪。
- 有对白时是否已按 [dialogue-capacity.md](dialogue-capacity.md) 估算口播、停顿和反应；对白是否挤压了动作结果。
- 只有高密度战斗块是否加载了 [combat-previs.md](combat-previs.md)；普通文戏是否误用了战斗专属规则。

## 分级门禁

- **P0 阻断**：块时长或镜头时间轴不成立；原台词/关键事件被改写或遗漏；生成块不能独立投喂；入口/出口状态断裂；严重跳轴、角色/场景/道具漂移。
- **P1 自动修复**：动作缺少可见结果；对白自然时长超预算；镜头全篇同节奏或切镜无动机；运镜、焦点或空间关系无法执行；专项规则加载错误。
- **P2 优化**：抽象形容词未物理化；镜头任务重复；空镜或重复凝视；环境与声音层次不足。

## 回退动作

若某个镜头质量不合格，按以下顺序处理：

1. 先定位失败类型：剧情越界、镜头不可执行、时长不成立、角色/空间不连续或提示词不自包含。
2. 优先只重写当前镜头或当前块中导致失败的字段，不改动无关内容。
3. 若同一镜头连续 2 次仍不合格，则重新切分该段镜头边界；15 秒仍必须回到五镜头结构。
4. 若重切后仍无法成立，则说明输入信息不足，转为追问用户。

## 追问原则

- 每次最多追问 3 个最关键问题。
- 优先问会直接影响分镜成立的缺失信息。
- 不追问与当前镜头无关的小细节。

## 禁止项

- 不要为了凑结果输出空泛镜头。
- 不要用重复镜头掩盖问题。
- 不要用无意义细节填充长度。
- 不要跳过质检直接输出。
