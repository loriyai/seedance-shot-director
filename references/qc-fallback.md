# 质量门禁与回退

## 硬检查

- 当前来源版本已锁定、可恢复；台词正文、人物和声音类型逐字覆盖，事件结果与信息顺序不变。一个事件可跨镜呈现但只发生一次，不能用重复状态锚点掩盖重演。
- 块标题明确实际时长与画幅，风格、人物、场景、氛围站位、收尾方式齐全；无模板占位符、后台审阅标记或缺失上下文。
- 时轴连续无缝，完整15秒严格五镜；自然短收尾仅在最后一块/最后两块，满足已核实入口最小值与步长，不超过模型上限。30秒通常8–12镜为建议，偏离提醒复核。
- 声音话轮ID、人物、类型和文本一致，区间匹配实际镜头覆盖；没有原文并发依据不重叠；无对白尾部不得被口播占用。确定的改词/漏词/错归属始终报错，未知部分另列待核。
- 剧情、素材绑定、道具归属、出入场路径、轴线和触发时序一致；表演在该景别角度可读。人物已知与观众已知分开，不能误删来源成立的画外触发。
- 增强强度符合配置；轻度只细化原动作，分镜不进行二次增强。新剧情建议未接受前不入稿。

## 估计与导演复核

声音速度使用净发音时间，与停顿分开。估计不确定时警告复核，不伪装确定性门禁；净发音高于5.2通常不持续超过3秒为经验提示。动作、阅读、反应和静音只计算真实未重叠部分。

检查动作是否完成、观看重点是否清楚、同一编号是否藏剪切、重复构图是否有信息/持续/对照价值。15秒通常至多一个不超过1.5秒的空镜，不连续空镜填秒。画面文字可读、显示与朗读分离。

执行简版删除重复、抽象风格词和无功能环境动态，保护剧情、声音、时间和连续性。详版规划置于块外，不增加视频正文负担。音乐与声线从配置编译，不出现互相矛盾的声音方案。

## 回退

1. 从来源和台账定位失败镜头，先修字段；两次仍不成立则重切视觉边界。
2. 容量或信息密度不成立时重划相邻块；短尾优先完整收尾，必要时联合调整最后两块时长。完整15秒仍五镜，不靠加速、慢念、重复或新动作修补。
3. 缺少关键叙事事实或实际入口无法容纳时，保留全文并只问阻断项；不能默认延期后宣称完成。
4. 更新受影响映射、版本和入口/出口；不重写无关块。

运行校验器并人工核对未解析部分。程序零错误仅说明已检查的结构和文字未发现确定错误，不代表表演、全剧情或实际视频效果通过。语义核对和真实生成反馈仍需要独立判断。
