# 质量门禁与回退

## 检查次数与停止条件

每份候选执行一次程序硬检查，再做一次来源与导演语义复核，下面两组清单分别供这两步使用，不各自发起多轮生成。统一规划编译器已内置硬检查，不对同一候选再单独跑校验器或重复人工计算同样的结构字段。

- 硬错误为零、语义复核通过、程序警告逐项复核且无阻断问题时，登记并立即交付。无需为P2美术措辞再跑优化循环；用户另提修改才开启新候选。
- 有实际错误时修对应规划字段和必要相邻关系；新候选重跑一次硬检查，语义只复核改动、关联连续性及仍未解决项目，继承未改内容的已核对结论。程序全文检查通常很快，不为了“增量”跳过对白覆盖与跨块时间约束。
- 未解析台词、事件遗漏、动作新增和物理连续性仍由语义复核覆盖，不能只看程序警告列表。计次不是放过错误的上限；达到停止条件才交付。
- 同一问题两次字段修复仍失败，按下文升级为重切或重划；缺少事实则明确阻断，不无休止重写整稿。

## 硬检查

- 当前来源版本已锁定、可恢复；台词正文、人物和声音类型逐字覆盖，事件结果与信息顺序不变。一个事件可跨镜呈现但只发生一次，不能用重复状态锚点掩盖重演。
- 块标题明确实际时长与画幅，风格、人物、场景、氛围站位与逐镜环境音效齐全，收尾方式只在后台；无模板占位符、后台审阅标记或缺失上下文。
- 时轴连续无缝，完整15秒默认五镜，可按表演与连续运镜需要调整；自然短收尾仅在最后一块/最后两块，满足已核实入口最小值与步长，不超过模型上限。30秒通常8–12镜为建议，偏离提醒复核。
- 后台声音话轮ID、人物、类型和文本一致，直投自然语言台词与后台一致，区间匹配实际镜头覆盖；没有原文并发依据不重叠；跨场景首末至少1秒及一般收束时段不得被任何口播占用；逐镜片段容量与整句预算都须通过。确定的改词/漏词/错归属始终报错，未知部分另列待核。
- 剧情、素材绑定、道具归属、出入场路径、轴线和触发时序一致；表演在该景别角度可读。人物已知与观众已知分开，不能误删来源成立的画外触发。
- 增强强度符合配置；轻度细化原动作，道具互动审阅提案经明确确认后入源，分镜不进行二次增强。新剧情建议未接受前不入稿。

## 估计与导演复核

声音速度使用净发音时间，与停顿分开。估计不确定时警告复核，不伪装确定性门禁；净发音高于5.2通常不持续超过3秒为经验提示。动作、阅读、反应和静音只计算真实未重叠部分。

检查动作是否完成、观看重点是否清楚、同一编号是否藏剪切、重复构图是否有信息/持续/对照价值。15秒通常至多一个不超过1.5秒的空镜，不连续空镜填秒。画面文字可读、显示与朗读分离。

执行简版删除重复、抽象风格词和无功能环境动态，保护剧情、声音、时间和连续性。详版规划置于块外，不增加视频正文负担。音乐与声线从配置编译，不出现互相矛盾的声音方案。

## 回退

1. 从来源和台账定位失败镜头，先修字段；两次仍不成立则重切视觉边界。
2. 容量或信息密度不成立时重划相邻块；短尾优先完整收尾，必要时联合调整最后两块时长。完整15秒默认五镜，可按真实摄影与表演调整，不靠加速、慢念、重复或新动作修补。
3. 缺少关键叙事事实或实际入口无法容纳时，保留全文并只问阻断项；不能默认延期后宣称完成。
4. 更新受影响映射、版本和入口/出口；不重写无关块。

运行校验器并人工核对未解析部分。程序零错误仅说明已检查的结构和文字未发现确定错误，不代表表演、全剧情或实际视频效果通过。语义核对和真实生成反馈仍需要独立判断。
