# 质量检查与回退

## 质量检查

输出前静默检查以下内容：

- 镜头数是否符合规则：15 秒必须 5 个，30 秒通常 8-12 个且由剧情决定。
- 时长是否动态分配且总和正确。
- 镜头时间端点是否递增、连续、无重叠，且没有残留占位符。
- 是否出现角色漂移、场景跳跃、道具漂移。
- 是否出现空泛、重复、偷懒式描述。
- 是否明确写出机位、运镜、景深、光线、音效和表演细节。
- 是否保持风格统一和空间连续性。
- 是否避免新增关键剧情、反转、人物关系或结局。
- 单个生成块是否自包含，脱离上下文仍有风格、画幅、总时长、角色、场景和连续性约束。

## 回退动作

若某个镜头质量不合格，按以下顺序处理：

1. 先定位失败类型：剧情越界、镜头不可执行、时长不成立、角色/空间不连续或提示词不自包含。
2. 优先只重写当前镜头或当前块中导致失败的字段，不改动无关内容。
3. 若同一镜头连续 2 次仍不合格，则重新切分该段镜头边界；15 秒仍必须回到五镜头结构。
4. 若重切后仍无法成立，则说明输入信息不足，转为追问用户。

## 追问原则

- 每次最多追问 3 个最关键问题。
- 优先问会直接影响分镜成立的缺失信息。
- 不追问与当前镜头无关的小细节。

## 禁止项

- 不要为了凑结果输出空泛镜头。
- 不要用重复镜头掩盖问题。
- 不要用无意义细节填充长度。
- 不要跳过质检直接输出。
