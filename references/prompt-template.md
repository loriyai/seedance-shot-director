# 直投提示词模板

由统一规划编译生成正文与后台台账。正文使用自然语言，不输出话轮ID、收尾模式、语速档、停顿预算或内部连续标签；这些字段仍参加后台校验。

## 台词与声音

普通对白：`台词：陈默说：“……”`
特殊语气：`台词：陈默压低声音说：“……”`
普通内心话：`台词：陈默内心OS：“……”`
特殊内心话：`台词：陈默以激昂、近乎呐喊的语气内心OS：“……”`

方括号占位符不进入实际正文。正常话轮不添加语气；特殊语气描述可听见的表现，不新增动机。OS仍为内心声音，呐喊式OS不使人物张嘴喊出；系统播报、旁白保持各自声音身份。同一话轮跨镜语气连续、不重新起调，原台词仅出现一次。

声音安排用本块绝对秒数写明实际起声、续说与结束，例如：`声音安排：12-13.1秒，接续本块前镜话语，语气连续；13.1秒结束本镜这部分口播。` 不以“最后留0.5秒”反向推迟台词起声，也不强迫声音说到留白起点。

每镜在全部台词下方输出`环境音效：`，无台词时放在摄影/表演描述之后。列当前镜头实际场景环境声与动作声，以中文“；”分隔；关键音效写明与动作的同步。原文有非语言笑声等可列在此，不能把对白、OS、系统台词偷放进音效。确无声音时明确静默，不凭空增加风雨、鸟鸣或其他剧情刺激。

## 正文骨架

```text
生成块 01｜15秒｜16:9
<当前风格的必要视觉特征>；<实际配乐选择>。
人物：<姓名、必要阶段及已提供的素材绑定>
场景：<当前空间与已有道具>
本块氛围与站位：<本场景光线与稳定空间关系>

[镜头1]
时间区间：0-X秒。
画面与动作：<可见行为、路径、起止及声画同步，不复述台词含义>
摄影机与构图：<景别、机位、主运动路径及终点>
声音安排：<实际起声和结束时刻>
台词：<角色名><必要时语气><说/内心OS/旁白>：“<原句>”
环境音效：<场景环境声>；<动作声>。

[镜头2]
时间区间：X-Y秒。
画面与动作：<承接的可见动作>
摄影机与构图：<观看对象、机位与运动>
衔接：<进入本镜的切镜方式；连续拍摄不另编号>
环境音效：<本镜真实声音>。
```

继续编号至本块结束。15秒默认五镜，可按表演、连续运镜和观看需求调整；一个编号是一段连续摄影，不把连续运动的阶段伪装成切镜。30秒通常8–12镜。删除占位符和不适用的可选字段，不删每镜环境音效。

## 无口播衔接时段

跨场景边界按 camera-transition.md 预留前块末尾及新块开头各至少1秒；地点相同但时间跳转也算新场景。正文写实际区间和本镜自然延续，例如：

`声音安排：14-15秒无口播，陈默继续沿土路走远，不定格；脚步声持续。`

这里的“无口播”包括对白、OS、旁白和系统播报，不代表完全无声、黑屏或空镜。首尾画面供用户后期剪辑，不自动增加淡出、叠化或匹配剪辑效果。首尾时段占用已有块时长，必须计入预算并核对。
