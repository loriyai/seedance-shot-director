# Seedance 提示词模板

## 输出目标

每个 `15 秒` 或 `30 秒` 生成块都应可单独复制，直接用于 Seedance 2.0 / 2.5。生成块是一次完整视频提示词，块内包含固定风格、固定规则和多个有明确时长的切镜；不把单个子镜头当成完整视频。

## 结构原则

- 后台按镜头逐条规划，不写成表格。
- 每个 15 秒生成块严格拆成 5 个镜头；每个 30 秒生成块通常拆成 8-12 个镜头，镜头数动态决定。
- 时长必须动态分配，不可机械平均。
- 每个生成块都要自包含；必须重复写入固定风格、固定规则、角色场景锚点和本块入口状态，块内镜头必须写出当前画面，不得依赖“上一镜”“下一镜”或“上一块”才能成立。
- 每个生成块按 [prompt-layering.md](prompt-layering.md) 组织为块级固定层、本块镜头变量层和分层负面约束层。
- 情绪戏要调用情绪微表情层，双人和群像戏要遵守空间轴线与连续性。
- 有对白时先执行 [dialogue-capacity.md](dialogue-capacity.md)；高密度战斗才调用 [combat-previs.md](combat-previs.md)。
- 默认最终输出全部生成块，每个块只保留可直接投喂的生成块正文；不要把同一内容先输出成审阅字段、再重复输出一遍提示词。

## 最终输出结构

每个生成块按以下顺序输出：

1. `生成块编号 / 总时长 / 画幅`
2. `中文提示词（可直接复制使用）`

默认最终输出每个生成块的编号、可直接复制标题和一整段提示词正文。每个提示词正文必须自行包含固定风格、固定规则、角色一致性、画幅、总时长、空间连续性、镜头时长和关键负面约束。

## 后台镜头记录字段

以下字段只用于后台规划、质检和局部修改，不默认逐项展示给用户。最终提示词须将这些信息压缩成自然语言并按镜头顺序写入：

1. `镜头 N`
2. `镜头任务`
3. `时长`
4. `画面`
5. `动作`
6. `起始状态 / 可见结果 / 结束状态`
7. `情绪`
8. `景别 / 视角角度 / 机位运镜 / 跟随目标`
9. `景深/焦点`
10. `光线/氛围`
11. `音效/环境音`
12. `表演细节`
13. `切镜动机与下一镜焦点承接`

## 写法要求

- `中文提示词（可直接复制使用）` 必须是可以直接投喂的自然语言段落；应按镜头顺序写清每个切镜及其内部时长。
- 用户只复制这一整块即可使用，不需要另行复制全局规则或镜头字段。
- 语言要短、准、稳，不要长篇解释。
- 抽象词必须落到可见细节上。
- 优先写主体、动作、情绪、场景、机位、景深、光线、音效和表演细节。
- 有台词或旁白时，保留原文并写明发声角色；无台词时不要擅自添加对白。
- 用户提供 `@素材` 时，原样保留其字符串、名称、顺序和位置。
- 可适度加入负面约束，如避免脸部漂移、避免多主体抢戏、避免动作失真。
- `情绪`字段必须对应情绪微表情层的可见动作，不写纯心理判断。
- 每个镜头必须有唯一主目标、可见起点、变化过程和可见结果；抽象词按 [shot-task-and-physicalization.md](shot-task-and-physicalization.md) 转译。
- `机位/运镜` 必须写清起点、方向、速度和终点；不移动时写“固定机位，不移动”。
- 双人或多人镜头的 `画面` 和 `机位/运镜` 必须符合空间轴线规则。
- 相邻镜头按 [camera-transition.md](camera-transition.md) 确定切镜动机和视觉焦点承接。

## 固定规则压缩写法

建议将固定规则压成一句，例如：

`3D写实国漫，人物一致，单镜头单目标，电影级调度，真实可执行，避免AI脸和漂移。`

这句话只是固定规则的压缩表达示例，不能替代生成块契约要求的固定风格、固定规则、角色场景锚点、入口状态和出口状态；这些内容必须在每个生成块中实际出现。

## 推荐生成块骨架

```text
生成块 01｜总时长：15秒｜画幅：16:9
中文提示词（可直接复制使用）
（固定层：固定风格、固定规则、画幅、总时长、角色与场景锚点、入口状态；变量层：按 0秒-X秒、X秒-Y秒……写清镜头任务、画面、动作闭环、情绪微动作、机位/运镜、景深/焦点、光线、声音和必要台词；负面层：按风险写通用和专项约束；最后锁定本块出口状态）
```

## 约束

- 不要把最终提示词写成表格或碎片字段堆砌；后台可以使用短字段。
- 不要重复空泛形容词。
- 不要用“电影感”“氛围感”去替代具体画面。
- 不要依赖上一镜或上一段内容。
- 不要把情绪、空间、局部修改等规则混写进镜头正文，相关要求应先在后台按对应 reference 处理。
- 不默认输出后台分析、叙事权重、资产建档、质检过程或修改说明。
